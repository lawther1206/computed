# 中国银行外汇牌价工具

一个用于获取并导出中国银行（BOC）人民币外汇牌价的 Electron 桌面工具。

## 功能

- 直接获取中国银行官网 `https://www.boc.cn/sourcedb/whpj/index.html`
- 解析官网当前公布的全部 40 个币种
- 默认选择澳大利亚元、加拿大元、捷克克朗、欧元、英镑、港币、日元、墨西哥比索、瑞典克朗、土耳其里拉、美元、阿联酋迪拉姆、沙特里亚尔、巴西雷亚尔
- 支持搜索、逐项多选、恢复默认 14 项、全选和清空
- 刷新按钮直接重新获取中国银行官网数据，并带 10 秒防重复请求倒计时
- 中行单位可在 `1` 和 `100` 之间切换，页面与 Excel 牌价同步换算
- 展示现汇买入价、现钞买入价、现汇卖出价、现钞卖出价和中行折算价
- 导出带官网来源、牌价时间和字段说明的 `.xlsx` 工作簿

官网原始牌价单位为 100 外币兑换人民币，应用可切换为 1 单位展示。实际交易价格以中国银行办理业务时为准。
